# Project Brief: MaxAdjust Mobile-First PWA

## Overview
MaxAdjust is a public insurance adjusters company based in New Jersey that helps property owners maximize their insurance claim settlements. The project aims to transform the existing Next.js website into a mobile-first Progressive Web App with clean, minimal design matching their business application.

## Business Context
MaxAdjust Public Adjusters represents property owners in insurance claims, typically achieving 180% higher settlements than what insurance companies initially offer. They handle fire damage, water damage, storm damage, mold damage, and commercial claims.

## Project Goals
1. Create a mobile-first PWA that matches the clean aesthetic of their business app
2. Prioritize mobile experience with bottom navigation and minimal imagery
3. Improve performance with <500KB initial load
4. Enable offline functionality and app installation
5. Streamline user journey to emergency contact and claim initiation

## Key Requirements
- **Design**: Match business app UI with blue/white color scheme, card-based layouts
- **Navigation**: Bottom navigation bar for mobile/tablet, traditional top nav for desktop only
- **Performance**: Mobile Lighthouse score 95+, works offline after first visit
- **Technology**: Next.js 15, pnpm, Tailwind CSS, PWA capabilities
- **Content**: Maintain existing service information while optimizing for mobile

## Success Metrics
- Users can install as native app on mobile devices
- One-thumb operation possible on mobile
- Emergency contact always accessible within one tap
- Page loads in <1.5s on 4G networks
- Simplified user flow increases conversion rates

## Target Audience
- Property owners experiencing damage emergencies
- Mobile-first users seeking immediate help
- Insurance claim filers needing professional representation
- Primarily New Jersey residents

## Project Scope
- Complete UI/UX redesign prioritizing mobile
- PWA implementation with offline support
- Performance optimization and image reduction
- Bottom navigation implementation
- Service page templates
- Contact flow optimization
